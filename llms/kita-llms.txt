# Kita

> Kita is an AI-native loan origination and underwriting company (Y Combinator W26, San Francisco) building document intelligence and credit decisioning for lenders in emerging and undertapped markets. It ships two developer-facing APIs: Kita Capture, which turns scanned financial and identity documents into structured, validated, fraud-checked JSON, and Kita AI Underwriter, which builds a loan file, computes a deterministic credit picture and synthesizes a cited credit memo.

Generated by the API Evangelist enrichment pipeline on 2026-07-19. Kita does not publish its own /llms.txt; this file is generated from Kita's public documentation and the artifacts in this repository.

Key facts an agent should know before calling Kita:
- Two separate APIs, two hosts, two key prefixes. Capture is `https://portal.usekita.com` with `kita_prod_` keys. Underwriter is `https://underwriter.kita.ai/api/v1` with `kita_uw_` keys.
- Both authenticate with `Authorization: Bearer <key>`. Underwriter also accepts `Authorization: ApiKey <key>` and enforces coarse `read` / `write` key scopes (403 when the scope is missing). There is no OAuth.
- Both are asynchronous. Submit, then poll. Capture additionally supports HMAC-signed webhooks; Underwriter does not support webhooks at all.
- Underwriter intake is idempotent on a caller-supplied `external_ref`. Always send one — there is no test mode, so a retry without it creates a duplicate application.
- Credit numbers (DSCR, ratios, policy decision) come from a versioned deterministic calculation engine, not from an LLM, and every value cites the source document line.
- There is no public sandbox, no test keys and no magic test values. Development runs against production on the free tier.

## APIs

- [Kita Capture API](https://www.kita.ai/capture): Document intelligence — extract structured, fraud-checked data from bank statements, payslips, invoices, government IDs, credit reports and 30+ other document types. Base URL https://portal.usekita.com
- [Kita AI Underwriter API](https://www.kita.ai/underwriting): Loan applications, borrower documents, deterministic credit picture and cited credit memo. Base URL https://underwriter.kita.ai/api/v1
